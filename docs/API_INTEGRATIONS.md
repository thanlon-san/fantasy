## 🚀 EXAMPLE: STOCK MARKET INTEGRATION

### 1. Install dependencies
```bash
pip install alpha-vantage
```

### 2. Add to `.env`
```
ALPHA_VANTAGE_KEY=your_key_here
```

### 3. Create enricher
```python
# src/api_enrichment.py
from alpha_vantage.timeseries import TimeSeries

def get_weekly_market_comparison(team_performance):
    ts = TimeSeries(key=os.getenv('ALPHA_VANTAGE_KEY'))
    data, _ = ts.get_weekly('SPY')
    
    latest_week = list(data.values())[0]
    week_change = calculate_change(latest_week)
    
    if team_performance < 0 and week_change > 0:
        return f"📈 S&P 500 up {week_change:.1f}% this week. Your fantasy team? Down {abs(team_performance):.1f}%. Maybe stick to index funds."
    
    return None
```

### 4. Update recap generator
```python

from src.api_enrichment import get_weekly_market_comparison
```
