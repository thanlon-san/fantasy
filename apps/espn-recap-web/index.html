🏈 ESPN Fantasy Recap Generator

AI-powered weekly recaps with personality

📝 About

Generate hilarious, insightful weekly recaps for your ESPN Fantasy Football league. Powered by Claude AI, this tool creates entertaining commentary with advanced analytics, power rankings, and automated Slack posting.

✨ Features

🤖 AI-Powered Recaps

Claude Opus 4.5 generates witty, personalized commentary for each matchup

📊 Power Rankings

Advanced opponent-adjusted scoring with season-phase weighting

💬 Slack Integration

Automatically post recaps to your league's Slack channel

📈 Advanced Analytics

Ownership trends, boom/bust analysis, and detailed stats

🚀 Quick Start

1. Clone & Install

git clone https://github.com/thanlon-san/fantasy.git cd fantasy/apps/espn-fantasy-recap pip install -r requirements.txt

2. Configure

cp config/env.example .env # Edit .env with your ESPN credentials and API keys

3. Run Server

npm run dev # Visit http://localhost:8000
Note: This is a Python backend tool that runs locally. The web UI connects to your local API server on port 8000.
