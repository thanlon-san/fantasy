# Baseball Dashboard

Modern web interface for the keeper-advisor tools.

## Features

- Daily lineup recommendations
- Waiver wire analysis
- Breakout player detection
- Keeper value analysis

## Development

```bash
pnpm install
pnpm dev  # Opens at localhost:3001
```
