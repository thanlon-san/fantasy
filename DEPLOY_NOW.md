### 1️⃣ Push to GitHub
```bash

git add .
git commit -m "Add baseball dashboard with GitHub Pages deploy"

```

### 2️⃣ Enable GitHub Pages
1. Go to: https://github.com/thanlon-san/fantasy/settings/pages
